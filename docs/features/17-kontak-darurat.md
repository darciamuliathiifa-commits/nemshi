# Kontak Darurat

Pengumpulan info kontak pengguna untuk keperluan verifikasi dan keamanan oleh admin Nemshi.

## Spesifikasi

### Tujuan
Mengumpulkan dan menyimpan informasi kontak darurat pengguna yang hanya dapat diakses oleh admin untuk keperluan verifikasi identitas, penanganan laporan keamanan, dan situasi darurat.

### Selesai bila
- Pengguna dapat mengisi formulir kontak darurat yang meminta nama lengkap kontak dan nomor telepon aktif.
- Sistem menyimpan data kontak darurat hanya untuk admin dan tidak ditampilkan ke publik.
- Admin dapat melihat data kontak darurat setiap pengguna di panel moderasi untuk keperluan verifikasi keamanan.

# Traktir Platform

Fitur apresiasi sukarela sebesar Rp5.000 sebagai dukungan setelah berhasil menemukan jasa/pelanggan.

## Spesifikasi

### Tujuan
Memberi pengguna cara mudah memberikan apresiasi sukarela sebesar Rp5.000 setelah mereka berhasil menemukan jasa atau pelanggan melalui Nemshi, sebagai dukungan untuk pengembangan platform.
### Selesai bila
- Tombol "Traktir Platform" dapat dilihat pengguna setelah mereka menyelesaikan suatu interaksi yang dianggap berhasil (misal setelah klik WhatsApp pada iklan jasa).
- Setelah tombol ditekan, pengguna diarahkan ke halaman pembayaran dengan nominal tetap Rp5.000.
- Pembayaran berhasil memunculkan pesan terima kasih dan konfirmasi bahwa donasi telah diterima.
- Admin dapat melihat total donasi "Traktir Platform" di laporan pendapatan.

## Task

### 1. Bangun halaman fitur Traktir dengan data dan interaksi tiruan

### 2. Poles tampilan notifikasi ucapan terima kasih setelah pembayaran tiruan

### 3. Buat skema basis data untuk pencatatan status penyelesaian transaksi

### 4. Buat endpoint API untuk mengecek dan memperbarui status konfirmasi keberhasilan
